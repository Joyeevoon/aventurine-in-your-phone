# 雾中的砂金 · 互动小游戏

隔着起雾的玻璃遇见砂金：擦雾、听他说话、点碎屏幕、贴贴纸、拍照做成明信片。



## 文件结构

```
index.html          页面入口
style.css           样式
app.js              游戏逻辑
assets/
  sj1.mp4           砂金 · 安静循环（1080×1920，30fps）
  sj2.mp4           砂金 · 说话循环
  poster1.webp      视频封面
  poster2.webp
  sticker1.png      星光眼贴纸
  sticker2.png      腮红贴纸
audio/
  bgm.mp3           背景音乐（雨夜的钢琴）
  line1.mp3         台词一：试着点击屏幕，带我离开这里？
  line2.mp3         台词二：不好，屏幕碎裂了……
  line3.mp3         台词三：……修好了。那就别走了，再陪我一会儿。
```

## 玩法

- 手指擦开玻璃上的水雾，6 秒后雾气自动散尽
- 点一下屏幕，玻璃会碎；点左上角「复原屏幕」修好
- 右上角：音乐开关 / 贴纸 / 拍照
- 拍完的明信片可以保存，也能直接分享到小红书
